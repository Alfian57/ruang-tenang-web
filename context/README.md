# Context Ruang Tenang Web
Context ini melengkapi README dan tidak menggantikan kode sebagai sumber kebenaran.

| Tugas | Baca |
| --- | --- |
| Memahami struktur frontend | architecture.md |
| Menambah atau mengubah halaman | features-and-routes.md |
| Mengubah request/response atau integrasi API | api-and-data-flow.md dan ecosystem.md |
| Mengubah env, Docker, PWA, atau CI | operations.md |
| Perubahan lintas aplikasi | ecosystem.md, lalu context API/mobile terkait |

Dokumen harus diperbarui ketika struktur, kontrak, atau workflow yang dijelaskannya berubah.
